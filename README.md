**Game 1 Radar** هو تطبيق ويب عصري وخفيف الوزن، صُمم خصيصاً لاصطياد وتتبع أحدث عروض الألعاب المجانية (بخصم 100%) من أشهر متاجر ومنصات الألعاب الرقمية مثل Steam، Epic Games، GOG، وغيرها. يتميز التطبيق بواجهة مستخدم أنيقة ويدعم التبديل الفوري بين اللغتين العربية والإنجليزية.

🌐 **رابط الموقع المباشر:** [game1radar.netlify.app](https://game1radar.netlify.app)

## ✨ المميزات (Features)

* **🔄 تحديثات حية (Real-Time Updates):** جلب أحدث العروض بشكل ديناميكي ومباشر باستخدام واجهة برمجة التطبيقات.
* **🛡️ فلترة ذكية للتطبيقات:** خوارزمية مخصصة لاستبعاد المحتوى غير المرغوب فيه مثل الإضافات (DLCs)، حزم العملات، وتطبيقات الخلفيات، لضمان عرض الألعاب الكاملة فقط.
* **🌍 ثنائي اللغة (Bilingual):** دعم كامل للغتين العربية (RTL) والإنجليزية (LTR) مع تبديل فوري وحفظ لحالة الواجهة بدون إعادة تحميل الصفحة.
* **🌙 الوضع الليلي الافتراضي (Dark Mode):** تصميم عصري مريح للعين مبني على تدرجات الألوان الداكنة (Slate & Gray) ليتناسب مع مجتمع اللاعبين.
* **📱 تصميم متجاوب (Responsive Design):** تجربة مستخدم مثالية على جميع الأجهزة (شاشات عريضة، أجهزة لوحية، هواتف ذكية) باستخدام CSS Grid و Flexbox.
* **⚡ أداء فائق:** مبني بالكامل باستخدام تقنيات الويب الأساسية (Vanilla JS) بدون الاعتماد على مكتبات ثقيلة، مما يضمن سرعة التحميل.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **HTML5:** الهيكلة الأساسية الدلالية (Semantic HTML).
* **CSS3:** تنسيق الواجهة، المتغيرات (CSS Variables)، تأثيرات الانتقال، والتجاوب عبر Media Queries.
* **JavaScript (Vanilla JS):** التعامل مع الـ DOM، الـ Fetch API لجلب البيانات، وإدارة حالة اللغات.
* **الخطوط:** خط [Tajawal](https://fonts.google.com/specimen/Tajawal) من Google Fonts لدعم الطباعة العربية والإنجليزية بشكل أنيق.

## 🚀 طريقة التشغيل المحلي (Local Setup)

لست بحاجة إلى بيئة تطوير معقدة أو خوادم لتشغيل هذا المشروع. اتبع الخطوات التالية:

1. **استنساخ المستودع (Clone the repo):**
   ```bash
   git clone https://github.com/YourUsername/game1radar.git
   ```

2. **الدخول إلى المجلد:**
   ```bash
   cd game1radar
   ```

3. **التشغيل:**
   * يمكنك ببساطة النقر المزدوج على ملف `index.html` لفتحه في متصفحك الافتراضي.
   * **(مستحسن)** استخدم إضافة مثل **Live Server** في محرر VS Code لتجربة تطوير أفضل مع التحديث التلقائي.

## 💡 الاستخدام (Usage)

1. عند فتح الموقع، سيقوم النظام تلقائياً بالبحث عن العروض المجانية المتاحة حالياً.
2. استخدم الزر في أعلى الصفحة (English / العربية) لتبديل لغة الواجهة بشكل فوري.
3. كل بطاقة لعبة تحتوي على صورة، السعر الأصلي (مشطوب)، منصة التشغيل، وزر "احصل عليها الآن".
4. انقر على "احصل عليها الآن" ليتم توجيهك مباشرة إلى صفحة العرض في المتجر الرسمي.

## 📡 مصدر البيانات (API Reference)

يستمد هذا المشروع بياناته الموثوقة من **[CheapShark API](https://apidocs.cheapshark.com/)**.

* **الرابط المستخدم:** `https://www.cheapshark.com/api/1.0/deals?upperPrice=0`
* نقوم بجلب الألعاب التي يصل سعرها إلى `0$` ونقوم بفلترتها داخل ملف `script.js` لعرض الأفضل للمستخدم.
